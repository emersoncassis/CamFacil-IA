O CamFácil IA é software livre (AGPL-3.0) para técnicos de segurança eletrônica aprenderem e validarem inteligência de vídeo. Este site serve apenas para login, pareamento e acompanhamento dos agentes. É gratuito e fornecido no estado em que se encontra, sem garantias.
