# Privacidade e LGPD

!!! warning "Ambiente de aprendizagem e validação"
    O CamFácil IA é para estudo e validação, sem garantias. A solução final no cliente é uma câmera ou gravador com IA de borda, ou uma plataforma profissional. O projeto **não coleta nem hospeda imagens**: quem opera é o técnico, responsável pela LGPD junto ao cliente.

## O que o software já faz por você

- Os dados ficam **na máquina do cliente**.
- **Modo LGPD:** rostos borrados no que sai da máquina.
- **Prazos de exclusão** configuráveis para clipes, arquivo do Telegram e fotos do modo estúdio.
- **Reconhecimento facial** nunca vem ligado e é bloqueado no modo estúdio.
- Cada aceite de termo fica registrado com data, hora e versão.
