# Design System

O sistema visual vigente está em [`DESIGN.md`](../DESIGN.md), na raiz do repositório, e os valores em [`web/tokens.css`](../web/tokens.css).

Resumo: painel escuro padrão do mercado de CFTV, base preta, verde (`#06cb3f`, inspirado na paleta Intelbras) só em detalhes. Projeto independente, sem vínculo com a Intelbras.

Histórico: a primeira versão (fundo verde-petróleo, cartões e botões verdes) foi rejeitada pelo autor em 2026-11-07 por parecer "cara de IA" e verde demais.
